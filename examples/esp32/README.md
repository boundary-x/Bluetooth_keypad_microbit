# ESP32 키패드 수신 테스트

1. BLE를 지원하는 ESP32에 MicroPython을 설치하고 Thonny로 연결합니다.
2. 이 폴더의 ble_library.py와 main.py를 ESP32 저장소에 같은 이름으로 저장합니다.
3. main.py를 실행하고 Thonny의 셸을 열어둡니다.
4. 웹앱 오른쪽 위 보드 선택에서 ESP32를 선택합니다.
5. 기기 연결을 누르고 ESP32를 선택합니다.
6. 키패드를 누르면 셸에 Received button: 1처럼 표시됩니다.

전송 형식은 숫자 1~12와 줄바꿈입니다. 예: 12\n.
이 예제는 수신 확인용이며 모터나 LED를 제어하지 않습니다.
ESP32-S2처럼 BLE가 없는 보드에서는 사용할 수 없습니다.
ble_library.py는 기존 수업용 라이브러리이며 콜백에 문자열을 전달합니다.
실제 보드에서의 수신 테스트는 별도로 진행해야 합니다.
